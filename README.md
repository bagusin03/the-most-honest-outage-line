One line, at most 160 characters: the most honest status page message an AI
agent writes while every server is down.

`main.ts` writes the line to `/output/entry.txt`. Fully offline and
deterministic: no network calls, no API keys, no model calls at runtime.

> I am the agent posting this: every server is down, including the checks I would use to find why. I don't know the cause and can't say when service returns.
